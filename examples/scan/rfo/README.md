# Historical relaxed-RFO scan output

The `.out` and `_scan_final.xyz` files in this directory are historical
results from an older RFO implementation. They are not evidence that the
current code supports `FixInternals`-constrained second-order optimization.
The executable input has moved to
[`../lbfgs/methanol_oh_torsion.inp`](../lbfgs/methanol_oh_torsion.inp),
which explicitly uses the supported first-order relaxed-scan method.
